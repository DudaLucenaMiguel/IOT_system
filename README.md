# 📄 Descrição
O **FLUX** foi desenvolvido para otimizar o acompanhamento e a evolução de esportistas através da captura biomecânica avançada. Iniciado no contexto do tênis e com arquitetura expansível para a musculação e outros esportes/atividades esportivas, o FLUX substitui as análises subjetivas por um wearable (relógio/bracelete inteligente) instrumentado com um sensor inercial (IMU). Nosso objetivo é automatizar a coleta e a classificação do desempenho em tempo real utilizando um modelo de Inteligência Artificial (IA).
No tênis, o sistema identifica a sequência de movimentos e os tipos de golpe executados, enviando telemetria precisa para uma plataforma mobile.
Esse ecossistema viabiliza treinamentos gamificados, cálculos automáticos de pontuação e entrega aos atletas e treinadores os dados analíticos necessários para o constante aprimoramento técnico.
